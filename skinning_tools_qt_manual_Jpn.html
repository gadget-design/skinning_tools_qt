1. ファイル構成

skinning_tools_qt は、次の 3 つのファイルでできています。

ファイル内容
skinning_tools_qt.pyツール本体（Python スクリプト）
skinning_tools_qt_manual_Jpn.htmlこのマニュアル（日本語）
skinning_tools_qt_manual_Eng.htmlマニュアル（英語）

2 つのマニュアルは、skinning_tools_qt.py と同じフォルダに置いてください。 ツールの ヘルプメニューの マニュアル (日本語) / マニュアル (英語) は、py ファイルと同じ場所にあるこれらのファイルを開きます。 別の場所に置くと、マニュアルを開けません。

2. 起動方法

Maya のスクリプトエディタの Python タブで、次を実行します。path は skinning_tools_qt.py を置いた場所に書き換えてください。

path = r"C:/tools/skinning_tools_qt.py"
with open(path, encoding="utf-8") as f:
    exec(compile(f.read(), path, "exec"))

スクリプトのフォルダに置いて import する場合は、次のように main() を呼びます。

import skinning_tools_qt
skinning_tools_qt.main()

すでにウィンドウが開いているときは、閉じてから開き直します。 シェルフのボタンに登録しておくと便利です。

3. 概要

skinning_tools_qt は、Maya のスキンウェイト作業をまとめて行うためのツールです。 ひとつのウィンドウで次の作業ができます。

  • スキンウェイトのペイント：Maya 標準のスキンウェイトペイントツールを、インフルエンスリスト・プリセット付きで操作する
  • 頂点ウェイトの設定１：選択した頂点(エッジ、フェイス)のウェイトを、ボタンで少しずつ足し引きする。
  • 頂点ウェイトの設定２：選択した頂点(エッジ、フェイス)のウェイトを、表（ウェイト表）で確認し、数値で直接編集する
  • コピー / ペースト：頂点のウェイトや、表のセルの値を、選択した順にコピー・ペーストする
  • インフルエンスのロック（ホールド）、追加・除去、未使用インフルエンスの除去など

ウェイトの調整のしかたは 3 通りあります。次の章「3 つの使い方」をまず読んでください。

画面は日本語と英語を切り替えられます（言語メニュー）。このマニュアルでは日本語表示の名前で説明し、 英語表示の名前を （English） のように併記します。

4. 3種類のウェイト調整の方法

このツールでは、次の 3種類の方法でウェイトを調整できます。目的に合わせて使い分けたり、組み合わせたりします。

ウェイト調整方法操作向いている作業
[方法1]. ブラシで塗る ペイントモード開始 を押し、ブラシでウェイトを塗る 広い範囲を大まかに整える、なめらかにする
[方法2]. 頂点を選んで 増減ボタンで調整する
 頂点を選択し、+0.01 / -0.01 などのボタンを押す（表のセルは選ばない） ポーズを付けた状態で、頂点の流れを見ながら細かく直す
[方法3]. ウェイト表のセルで調整する 頂点を選択し、ウェイト表のセルを選んで、増減ボタンを押すか数値を入力する 決まった値を正確に入れる、特定の頂点・インフルエンスだけを直す
  • 方法1 の詳しい説明は「スキンウェイトのペイント」、方法3 は「ウェイト表」を見てください。
  • 方法2 と 3 は同じボタン（加算 / 減算プリセット）を使います。どちらになるかは、ウェイト表のセルを選んでいるかどうかで決まり、ステータスの表示で見分けられます。

[方法 2]「頂点を選んでボタンで調整する について

ウェイト表のセルを選ばずに、選択した頂点のウェイトをボタンで足し引きする方法です。 インフルエンス（ジョイント）を一時的に移動・回転させてメッシュを変形させた状態で、 ワイヤフレーム表示の頂点の流れ（エッジループ）を見ながら、選んだ頂点のウェイトを少しずつ調整できます。 ボタンを押すたびにメッシュの変形がすぐ変わるので、結果を目で確かめながら作業できます。

手順

  1. スキンを適用したメッシュを選択します。スキンクラスターがツールに読み込まれます。
  2. 調整したい部分のインフルエンス（ジョイントなど）を一時的に移動・回転させて、変形が見えるポーズにします。
  3. コンポーネントモード開始 を押し、調整したい頂点を選択します。ステータスが ステータス：バーテックス になります。
  4. インフルエンスリスト（またはウェイト表の列見出しの名前）で、ウェイトを増やしたい / 減らしたいインフルエンスを選択します。
  5. 頂点ウェイトの設定 の 加算（+0.001〜+0.10）/ 減算（-0.001〜-0.10）のボタンを押します。選択中のすべての頂点に、その値が足し引きされます。
  6. 変形による頂点の流れ（エッジループ）を見ながら、4〜6 をくり返します。頂点の選び直し、インフルエンスの選び直しは何度でもできます。
  7. 終わったら、移動・回転させたインフルエンスを元の位置・角度に戻します。

ポイント

  • セルを選ばないこと：ウェイト表のセルを選んでいると、増減ボタンはセルに対して働きます（使い方 3）。セルの選択は、表の空いている所をクリックするか、列見出しの名前をクリックすると外れます。
  • ボタンの使い分け：±0.10 / ±0.05 で大まかに、±0.01 / ±0.001 で細かく合わせます。
  • ほかのインフルエンスへの影響：ウェイトの正規化が ON のときは、足した分だけほかのインフルエンスのウェイトが減ります（減らしたときは増えます）。動かしたくないインフルエンスは、先にロックしておくと値が変わりません。
  • 複数のインフルエンス：インフルエンスを複数選んでいると、それぞれに同じ値を足し引きします。
  • 値の範囲：結果は 0〜1 に収まります。
  • 選んだインフルエンスがロック中のときは、メッセージを出してそこで止まります。アンロックしてから押し直してください。
  • ウェイト表には選択中の頂点の値が出るので、ボタンを押したときの値の変化も確認できます。

7. スキンウェイトのペイント

2ペイントモード開始 / 終了

  • ペイントモード開始 （Start Paint Mode）：読み込み中のスキンクラスターのジオメトリを選択し、スムーズシェーディング表示にして、Maya のスキンウェイトペイントツールに入ります。リストで何も選択していないときは、ペイントツールで現在ペイント対象のインフルエンスをリストで選択します。
  • ペイントモード終了 （End Paint Mode）：選択ツールに戻ります。

3全てロック / 全てアンロック・スキンクラスター欄

  • 全てロック / 全てアンロック：リストのすべてのインフルエンスのウェイトをロック / アンロックします。
  • スキンクラスター欄：読み込み中のスキンクラスター名です。名前を入力して Enter で、そのスキンクラスターを読み込みます。 右クリックで スキンクラスターノードを選択 / ジオメトリを選択 ができます。

スキンクラスターのインフルエンスの一覧です。リストで選んだインフルエンスがペイントの対象になります。

ロックボタンを押したまま上下にドラッグなぞった行を、押した行と同じロック状態にします。
名前をダブルクリックロック / アンロックを切り替えます。複数選択中のどれかをダブルクリックすると、選択中のものをまとめて切り替えます。

5ブラシ形状・ペイント操作・カラー / 白黒

  • ブラシ形状：左から ガウス / ポリゴン / ソリッド です。
  • ペイント操作：置き換え （Replace） / 追加 （Add） / スケール （Scale） / スムーズ （Smooth）。選んだ操作は次回の起動でも引き継がれます。
  • カラー / 白黒 （Color or Mono）：ペイント中のウェイトの表示を、カラーとモノクロで切り替えます。

6不透明度・値・塗りつぶす

  • 不透明度 （Opac） / 値 （Val）：ペイントツールの不透明度と値です。数値欄に入力するか、スライダーで変えます。設定は次回の起動でも引き継がれます。
  • 塗りつぶす （Flood）：選択中のインフルエンスに、今の操作・不透明度・値で、ジオメトリ全体を塗りつぶします。ペイントモード中だけ使えます。

7プリセット（加算 / 乗算）

ボタンを押すと、ペイント操作と値をまとめて設定します。

  • 加算（赤いボタン +0.01 / +0.02 / +0.10 / +0.20）：操作を「追加」にし、値をその数値にします。
  • 乗算（青いボタン x0.80 / x0.90 / x0.98 / x0.99）：操作を「スケール」にし、値をその数値にします。

ウィンドウの幅が狭いときは、ボタンが次の行に折り返されます。

8. 頂点ウェイトの設定

9コンポーネントモード開始 / 終了

  • コンポーネントモード開始：読み込み中のスキンクラスターのジオメトリを選択し、コンポーネント（頂点）選択モードにします。 頂点だけでなく、エッジやフェイスを選択しても、その上の頂点がウェイト表に表示され、ウェイトを操作できます（エッジ / フェイスを選択したとき）。
  • コンポーネントモード終了：オブジェクト選択モードに戻ります。

10加算 / 減算プリセット

+0.001 / +0.01 / +0.05 / +0.10 と、そのマイナスのボタンで、ウェイトに値を足し引きします。対象は次のとおりです。

  • セルを選択していないとき（ステータス：バーテックス）：シーンで選択中のすべての頂点の、インフルエンスリストで選択中のインフルエンス。 → 使い方 2：頂点を選んでボタンで調整する
  • ウェイト表のセルを選択しているとき（ステータス：セル）：選択中のセル。 → 使い方 3（ウェイト表）

結果は 0〜1 の範囲に収まります。ロック中のインフルエンスの値は変更されません（頂点を選択中に、ロック中のインフルエンスを選んで押すと、メッセージを出してそこで止まります）。

11ステータス

ウェイト表の上に、今の選択の状態を表示します。コピー / ペーストとプリセットの対象は、この表示で見分けられます。

表示状態
ステータス：（白）頂点もセルも選択していない
ステータス：バーテックス（黄色）シーンで頂点（エッジ・フェイス）を選択している
ステータス：セル（青）ウェイト表のセルを選択している

ウェイト表の列見出し（インフルエンス名）の色も、ステータスと同時に変わります。セルを選択しているときは青、それ以外（頂点を選択しているときなど）はオレンジです。

12ウェイト表

選択した頂点のウェイトを一覧にした表です。行が頂点、列がインフルエンスです。

  • 表示する頂点：シーンで選択した頂点を、選択した順に並べます。頂点を選ばずにオブジェクトを選択しているときは、そのオブジェクトの全頂点を出します。表示は最大 1000 頂点までです。
  • エッジ / フェイスを選択したとき：選択したエッジ / フェイス上の頂点を表示します。エッジ / フェイスを選択した順に、それぞれの頂点を頂点番号順で並べます（隣り合うエッジ / フェイスで共有する頂点は 1 回だけ）。 頂点を選んだときと同じように、加算 / 減算プリセット・コピー / ペーストでウェイトを操作できます（エッジ / フェイス上の頂点が対象。表のセルを選べば、数値の入力やセルの操作もできます）。
  • 表示する列：表示中の頂点のどれかで、0 より大きいウェイトを持つインフルエンスだけを出します。
  • 表に無いインフルエンスを選んだとき：インフルエンスリストで、表に出ていないインフルエンスを選択すると、表の右端にその列見出し（名前）だけを出します。列見出しの色はグレー系になり、下のセルは空欄で、選択・編集はできません。 見出しは選択中の色になり、ロックスイッチやクリックでの選択も使えます。リストで選択を外すと消えます。 加算プリセットなどでウェイトが 0 より大きくなると、値の入った普通の列になります。
  • 行見出しは頂点番号です。
  • 列見出しの色：セルを選択しているときは青、それ以外（頂点を選択しているときなど）はオレンジです（ステータスと同時に切り替わります）。選択中のインフルエンスの見出しは、それぞれ明るい色になります。

列見出し（インフルエンス名）の操作

操作はたらき
名前の部分をクリックそのインフルエンスを選択します（インフルエンスリストの選択と連動し、ペイント対象も切り替わります）。Ctrl / Shift も使えます。セルを選択していたときは、セルの選択を解除します。
名前の部分をダブルクリックロック / アンロックを切り替えます。
下端の鍵のアイコンをクリックロック / アンロックを切り替えます。

ロック中のインフルエンスの列は、セルが灰色になり編集できません。ロックはインフルエンスリストと共通なので、どちらで切り替えても両方に反映されます。

セルの操作

操作はたらき
クリック / ドラッグ / Ctrl・Shift + クリックセルを選択します。
セルを選んで数字を入力（または ダブルクリック / F2）値を編集します。Enter で確定すると、選択中のすべてのセルに同じ値が入ります（ロック中の列を除く）。
表の空いている所・行見出し・左上の角をクリックセルの選択と、インフルエンスの選択を解除します。

値を入れたときの正規化

スキンクラスターのウェイトの正規化が ON のときは、頂点ごとに合計が 1.0 になるよう、 入力していないインフルエンスのウェイトを元の比率のまま増減させます。ロック中のインフルエンスの値は変わりません。 入力値がロック分を除いた残りより大きいときは、入力値のほうを縮めて収めます。

9. コピー / ペースト

13コピー / ペースト ボタンは、ステータスによって、扱うものが変わります。 頂点用とセル用のコピー内容は別々に覚えています。ペーストボタンには、そのときペーストされる数が ペースト (3) のように表示されます。

頂点を選択しているとき（ステータス：バーテックス）

頂点のウェイト（すべてのインフルエンスの値）を、頂点から頂点へコピーします。

  1. コピー元の頂点を、1 つずつ順番に選択します（2 つ目からは Shift + クリック）。
  2. コピー を押します。
  3. ペースト先の頂点を、同じように 1 つずつ順番に選択します。
  4. ペースト を押すと、1 つ目のコピー元 → 1 つ目のペースト先、2 つ目 → 2 つ目…の順にウェイトが入ります。
  • コピーした頂点が 1 つだけのときは、選択したすべての頂点に同じウェイトを入れます。
  • 別のメッシュにもペーストできます。ただし、コピーしたウェイトのインフルエンスがペースト先のスキンクラスターに無いときは、ペーストせずに警告を出します。

セルを選択しているとき（ステータス：セル）

ウェイト表のセルの値を、セルからセルへコピーします。

  1. コピー元のセルを、1 つずつ順番に選択します（2 つ目からは Ctrl + クリック）。
  2. コピー を押します。
  3. ペースト先のセルを、同じように 1 つずつ順番に選択します。
  4. ペースト を押すと、選んだ順に値が入ります。
  • コピーしたセルが 1 つだけのときは、選択したすべてのセルに同じ値を入れます。
  • ペースト後の正規化は、セルに数値を入力したときと同じです（ウェイト表の「値を入れたときの正規化」）。
  • Shift + クリックやドラッグでまとめて選んだセルは、その中では表の並び順（上の行から、左の列から）になります。

どちらにも共通

  • ロック中のインフルエンスは、自動でアンロックしてからペーストします。アンロックしたインフルエンスはスクリプトエディタに表示され、ペースト後もアンロックのままです。
  • コピーした数と選択した数が違うときは、先頭から順に組にしてペーストし、余った分にはペーストしません（警告が出ます）。
  • ペーストは Ctrl + Z 1 回で元に戻せます（自動のアンロックも戻ります）。

10. 作業例

使い方 1：ペイントでウェイトを整える

  1. スキンを適用したメッシュを選択します（スキンクラスターが自動で読み込まれます）。
  2. ペイントモード開始 を押します。
  3. 動かしたくないインフルエンスをロックし、インフルエンスリストでペイントするインフルエンスを選びます。
  4. プリセット（例：加算 +0.02、乗算 x0.90）を押して、少しずつ塗り重ねます。最後に スムーズ でならします。

使い方 2：ポーズを付けて、頂点の流れを見ながら直す

肘を曲げたときのつぶれ方を直す例です。詳しくは「使い方 2：頂点を選んでボタンで調整する」を見てください。

  1. 肘のジョイントを選択し、90 度ほど回転させます。
  2. ビューをワイヤフレーム表示にし、コンポーネントモード開始 を押します。
  3. 肘の内側でつぶれているエッジループの頂点を選択します。
  4. インフルエンスリストで上腕のジョイントを選び、+0.05 や +0.01 を押して、つぶれが直るまで調整します。
  5. 隣のエッジループの頂点を選び直して、同じように調整します。
  6. 最後に、肘のジョイントの回転を元に戻します。

使い方 3：数値でウェイトを直す

  1. コンポーネントモード開始 を押し、直したい頂点を選択します。
  2. ウェイト表で、直したいセルを選びます（複数可）。
  3. 数字を入力して Enter、または 加算 / 減算 のプリセットで少しずつ調整します。

左右対称の頂点にウェイトを写す

  1. 写し元の頂点を 1 つずつ順に選択し、コピー。
  2. 写し先の頂点を、写し元と対応する順に 1 つずつ選択し、ペースト。

※ 左右でインフルエンス名が違う（L_arm と R_arm など）場合、インフルエンスは名前どおりに入ります。左右の入れ替えは行いません。

11. 注意事項

  • 選択順の記録：頂点を選択した順を使うため、ツールの起動時に Maya の「選択順の記録」（selectPref -trackSelectionOrder）を ON にします。Maya 全体の設定なので、ツールを閉じても ON のままです。ツールを起動する前に選んでいた頂点は、選択順が記録されていないことがあります。その場合は頂点番号順になります。
  • 表示の上限：ウェイト表に出せるのは 1000 頂点までです。超えた分は表示されません（スクリプトエディタにメッセージが出ます）。
  • Undo：ウェイト表でのセルの編集、セルを選択中のプリセット、ペーストは、それぞれ Ctrl + Z 1 回で元に戻せます。頂点を選択中（セルを選んでいないとき）のプリセットは、選んだインフルエンスごとに書き込むため、インフルエンスを複数選んでいると、元に戻すには複数回の Undo が必要になります。値が 0〜1 をはみ出して丸められた頂点があると、さらに回数が増えます。Undo / Redo の後は、表とロックの表示も自動で更新されます。
  • メッセージ：警告や処理の結果は、Maya のスクリプトエディタとステータスラインに表示されます。
  • 複数のシェイプ：1 つのトランスフォームの下に複数のシェイプがあるオブジェクトでは、意図しない結果になることがあります（警告が出ます）。
