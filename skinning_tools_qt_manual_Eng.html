2. Launching the tool

Run the following in the Python tab of Maya's Script Editor. Replace path with the location of skinning_tools_qt.py.

path = r"C:/tools/skinning_tools_qt.py"
with open(path, encoding="utf-8") as f:
    exec(compile(f.read(), path, "exec"))

If you put the file in a scripts folder and import it, call main() as follows.

import skinning_tools_qt
skinning_tools_qt.main()

If the window is already open, it is closed and reopened. Registering this as a shelf button is convenient.

3. Overview

skinning_tools_qt is a tool for doing skin weight work in Maya from a single window. It lets you do the following.

  • Paint Skin Weights: operate Maya's standard Paint Skin Weights tool with an influence list and presets
  • Set Vertex Weights (1): add to or subtract from the weights of the selected vertices (edges, faces) in small steps with buttons
  • Set Vertex Weights (2): view the weights of the selected vertices (edges, faces) in a table (the weight table) and edit them directly as numbers
  • Copy / Paste: copy and paste vertex weights or table cell values in the order they were selected
  • Locking (holding) influences, adding / removing influences, removing unused influences, and more

There are three ways to adjust weights. Read the next chapter, "Three ways to adjust weights", first.

The UI can be switched between Japanese and English (Language menu). This manual uses the names shown in the English UI.

4. Three ways to adjust weights

This tool offers the following three ways to adjust weights. Use whichever fits the task, or combine them.

MethodOperationBest for
[Method 1] Paint with a brush Press Start Paint Mode and paint weights with the brush Roughly shaping or smoothing large areas
[Method 2] Select vertices and adjust with the add / subtract buttons
 Select vertices and press buttons such as +0.01 / -0.01 (do not select cells in the table) Fine-tuning while watching the vertex flow in a posed state
[Method 3] Adjust with cells in the weight table Select vertices, select cells in the weight table, then press the add / subtract buttons or type a value Entering exact values, or fixing only specific vertices / influences
  • For details, see "Paint Skin Weights" for Method 1 and "Weight table" for Method 3.
  • Methods 2 and 3 use the same buttons (Add / Sub presets). Which one applies depends on whether cells in the weight table are selected; you can tell from the status display.

About [Method 2] "Adjusting selected vertices with buttons"

This method adds to or subtracts from the weights of the selected vertices with buttons, without selecting cells in the weight table. You can temporarily move / rotate influences (joints) to deform the mesh, and then adjust the weights of the selected vertices little by little while watching the vertex flow (edge loops) in wireframe. Each button press immediately updates the mesh deformation, so you can check the result visually as you work.

Steps

  1. Select a skinned mesh. Its skin cluster is loaded into the tool.
  2. Temporarily move / rotate the influences (joints, etc.) around the area you want to adjust, so that the deformation is visible.
  3. Press Start Component Mode and select the vertices to adjust. The status becomes Status: Vertex mode.
  4. In the influence list (or by clicking a name in the column headers of the weight table), select the influence whose weight you want to increase / decrease.
  5. Press an Add (+0.001 to +0.10) / Sub (-0.001 to -0.10) button in Set Vertex Weights. The value is added to / subtracted from all selected vertices.
  6. Repeat steps 4 to 6 while watching the vertex flow (edge loops) of the deformation. You can reselect vertices and influences as many times as you like.
  7. When finished, return the moved / rotated influences to their original position and rotation.

Tips

  • Do not select cells: if cells in the weight table are selected, the add / subtract buttons act on the cells (Method 3). To deselect cells, click an empty area of the table or click a name in the column headers.
  • Choosing buttons: use ±0.10 / ±0.05 for rough changes and ±0.01 / ±0.001 for fine adjustment.
  • Effect on other influences: when weight normalization is ON, the weights of other influences decrease by the amount you add (and increase when you subtract). Lock any influences you do not want to change beforehand, and their values stay the same.
  • Multiple influences: if several influences are selected, the same value is added to / subtracted from each of them.
  • Value range: results are clamped to 0 to 1.
  • If a selected influence is locked, a message is shown and the operation stops. Unlock it and press the button again.
  • The weight table shows the values of the selected vertices, so you can also check how the values change when you press a button.

7. Paint Skin Weights

2Start / End Paint Mode

  • Start Paint Mode: selects the geometry of the loaded skin cluster, switches to smooth shading, and enters Maya's Paint Skin Weights tool. If nothing is selected in the list, the influence currently being painted in the paint tool is selected in the list.
  • End Paint Mode: returns to the Select tool.

3Lock All / Unlock All, Skin Cluster field

  • Lock All / Unlock All: locks / unlocks the weights of all influences in the list.
  • Skin Cluster field: the name of the loaded skin cluster. Type a name and press Enter to load that skin cluster. Right-click to use Select Skin Cluster Node / Select Geometry.

4Influence list

The list of influences of the skin cluster. The influences selected in the list are the paint targets.

5Brush shape, paint operation, Color or Mono

  • Brush shape: from the left, Gaussian / Poly / Solid.
  • Paint operation: Replace / Add / Scale / Smooth. The chosen operation is kept the next time the tool starts.
  • Color or Mono: switches the weight display while painting between color and monochrome.

6Opac, Val, Flood

  • Opac / Val: the opacity and value of the paint tool. Type in the number field or use the slider. The settings are kept the next time the tool starts.
  • Flood: floods the whole geometry for the selected influence with the current operation, opacity, and value. Available only in paint mode.

7Presets (add / scale)

Pressing a button sets the paint operation and value at once.

  • add (red buttons +0.01 / +0.02 / +0.10 / +0.20): sets the operation to "Add" and the value to that number.
  • scale (blue buttons x0.80 / x0.90 / x0.98 / x0.99): sets the operation to "Scale" and the value to that number.

When the window is narrow, the buttons wrap to the next line.

8. Set Vertex Weights

9Start / End Component Mode

  • Start Component Mode: selects the geometry of the loaded skin cluster and switches to component (vertex) selection mode. Not only vertices: if you select edges or faces, the vertices on them are shown in the weight table and you can edit their weights (see When edges / faces are selected).
  • End Component Mode: returns to object selection mode.

10Add / Sub presets

The +0.001 / +0.01 / +0.05 / +0.10 buttons and their negative counterparts add to / subtract from weights. The targets are as follows.

  • When no cells are selected (Status: Vertex mode): the influences selected in the influence list, on all vertices selected in the scene. → Method 2: Adjusting selected vertices with buttons
  • When cells in the weight table are selected (Status: Cell mode): the selected cells. → Method 3 (Weight table)

Results are clamped to the range 0 to 1. The values of locked influences are not changed (if vertices are selected and you press a button with a locked influence selected, a message is shown and the operation stops).

11Status

Shows the current selection state above the weight table. Use this display to tell what Copy / Paste and the presets will act on.

DisplayState
Status: (white)Neither vertices nor cells are selected
Status: Vertex mode (yellow)Vertices (edges, faces) are selected in the scene
Status: Cell mode (blue)Cells in the weight table are selected

The color of the column headers (influence names) of the weight table changes together with the status: blue while cells are selected, and orange otherwise (for example, while vertices are selected).

12Weight table

A table listing the weights of the selected vertices. Rows are vertices and columns are influences.

  • Vertices shown: the vertices selected in the scene, in the order they were selected. If an object is selected without selecting vertices, all vertices of that object are shown. Up to 1000 vertices are shown.
  • When edges / faces are selected: the vertices on the selected edges / faces are shown, in the order the edges / faces were selected, with each one's vertices in vertex-number order (vertices shared by neighboring edges / faces appear only once). Just as when vertices are selected, you can edit the weights with the Add / Sub presets and Copy / Paste (they act on the vertices of the edges / faces; if you select cells in the table, you can also type values and work on cells).
  • Columns shown: only influences that have a weight greater than 0 on at least one of the displayed vertices.
  • Selecting an influence that is not in the table: if you select an influence in the influence list that is not shown in the table, only its column header (name) is shown at the right end of the table. The header is shown in gray, and the cells below it are blank and cannot be selected or edited. The header is shown in the selected color, and its lock switch and click-to-select work as usual. It disappears when you deselect it in the list. Once its weight becomes greater than 0 (for example with the Add presets), it becomes a regular column with values.
  • Row headers show vertex numbers.
  • Column header color: blue while cells are selected, orange otherwise (for example, while vertices are selected). It switches together with the status. Headers of selected influences are shown in a lighter shade of each color.

Column header (influence name) actions

ActionFunction
Click the name areaSelects that influence (linked with the selection in the influence list; the paint target also changes). Ctrl / Shift can also be used. If cells were selected, the cell selection is cleared.
Double-click the name areaToggles lock / unlock.

Columns of locked influences have gray cells and cannot be edited. Locks are shared with the influence list, so toggling in either place is reflected in both.

Cell actions

ActionFunction
Click / drag / Ctrl or Shift + clickSelects cells.

Normalization when entering values

The value you enter goes into the cell as it is. When weight normalization of the skin cluster is ON, Maya's normalization adjusts the weights of the influences you did not edit so that each vertex totals 1.0 (the same as entering a value in the Component Editor).

9. Copy / Paste

13What the Copy / Paste buttons handle depends on the status. Copied data for vertices and for cells is stored separately. The Paste button shows the number of items that will be pasted, like Paste (3).

When vertices are selected (Status: Vertex mode)

Copies vertex weights (the values of all influences) from vertex to vertex.

  1. Select the source vertices one at a time, in order (Shift + click from the second one on).
  2. Press Copy.
  3. Select the destination vertices one at a time, in order, in the same way.
  4. Press Paste. The weights are pasted in order: 1st source → 1st destination, 2nd → 2nd, and so on.
  • If only one vertex was copied, the same weights are pasted to all selected vertices.
  • You can also paste to another mesh. However, if an influence in the copied weights does not exist in the destination skin cluster, nothing is pasted and a warning is shown.

When cells are selected (Status: Cell mode)

Copies cell values in the weight table from cell to cell.

  1. Select the source cells one at a time, in order (Ctrl + click from the second one on).
  2. Press Copy.
  3. Select the destination cells one at a time, in order, in the same way.
  4. Press Paste. The values are pasted in the order selected.
  • If only one cell was copied, the same value is pasted to all selected cells.
  • Normalization after pasting is the same as when typing a value into a cell ("Normalization when entering values" in Weight table).
  • Cells selected together with Shift + click or by dragging are ordered as in the table (top row first, left column first).

Common to both

  • Locked influences are unlocked automatically before pasting. The unlocked influences are listed in the Script Editor and remain unlocked after pasting.
  • If the number copied differs from the number selected, items are paired from the beginning and the extras are not pasted (a warning is shown).
  • A paste can be undone with a single Ctrl + Z (including the automatic unlock).

10. Workflow examples

Method 1: Shaping weights by painting

  1. Select a skinned mesh (its skin cluster is loaded automatically).
  2. Press Start Paint Mode.
  3. Lock the influences you do not want to change, and select the influence to paint in the influence list.
  4. Press a preset (for example add +0.02 or scale x0.90) and paint in layers little by little. Finish by evening things out with Smooth.

Method 2: Posing and fixing while watching the vertex flow

An example of fixing how an elbow collapses when bent. For details, see "Method 2: Adjusting selected vertices with buttons".

  1. Select the elbow joint and rotate it about 90 degrees.
  2. Switch the view to wireframe and press Start Component Mode.
  3. Select the vertices of the collapsing edge loop on the inside of the elbow.
  4. Select the upper arm joint in the influence list and press +0.05 or +0.01 until the collapse is fixed.
  5. Select the vertices of the neighboring edge loop and adjust them the same way.
  6. Finally, return the elbow joint's rotation to its original value.

Method 3: Fixing weights with numbers

  1. Press Start Component Mode and select the vertices to fix.
  2. In the weight table, select the cells to fix (multiple cells allowed).
  3. Type a number and press Enter, or adjust little by little with the Add / Sub presets.

Copying weights to symmetrical vertices

  1. Select the source vertices one at a time in order, then press Copy.
  2. Select the destination vertices one at a time in the order matching the source, then press Paste.

* If the left and right influence names differ (such as L_arm and R_arm), weights go to the influences with the same names. Left and right are not swapped.

11. Notes

  • Recording the selection order: because the order in which vertices are selected is used, the tool turns on Maya's "Track selection order" (selectPref -trackSelectionOrder) when it starts. This is a Maya-wide setting, so it stays ON even after the tool is closed. For vertices selected before the tool was started, the selection order may not have been recorded; in that case they are ordered by vertex number.
  • Display limit: the weight table can show up to 1000 vertices. Vertices beyond that are not shown (a message appears in the Script Editor).
  • Undo: cell edits in the weight table, presets applied while cells are selected, and pastes can each be undone with a single Ctrl + Z. Presets applied while vertices are selected (with no cells selected) are written per selected influence, so if several influences are selected, multiple undos are needed. If any vertex had its value clamped to the 0 to 1 range, even more undos are needed. After Undo / Redo, the table and lock display are updated automatically.
  • Messages: warnings and results are shown in Maya's Script Editor and on the status line.
  • Multiple shapes: objects with multiple shapes under one transform may give unexpected results (a warning is shown).
